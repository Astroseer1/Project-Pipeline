# Project Pipeline

小游戏自动化生产流水线 — 从选品到迭代的全流程工具链。

## 🎮 第一个游戏：Hue Sensei / 辨色达人

> 边玩边学中英文颜色名！

[👉 在线玩](https://astroseer1.github.io/Project-Pipeline/index.html)

## 🏗️ 项目架构

```
① 选品 → ② 开发 → ③ 发布 → ④ 运营 → ⑤ 迭代
```

## 🛠️ 技术栈

- 游戏：纯 HTML5 / Canvas / JS，零依赖，单文件
- 爬虫：Node.js + cheerio
- 数据：JSON 文件驱动
- 引擎：Claude Code 全流程自动化

## 📂 目录

- `games/` — 游戏源码
- `skills/` — 自动化 Skill 定义
- `tools/` — 爬虫 / 评分 / 打包脚本
- `data/` — 玩法基因库 + 选品数据
- `docs/` — 设计文档 + 实现计划
